01

The idea

Create a clear introduction to Minahil Ilyas and her Information Technology studies. The website brings an about page, technical interests and a growing portfolio into one consistent experience.

02

What’s implemented

The site uses original HTML and CSS to present separate pages for my profile, technical interests and project details. Project cards link directly to their full descriptions. The layout adjusts to different screen widths, and the navigation works without JavaScript.

03

Connecting the studies

Semantic elements organise each page, while CSS selectors define the presentation. Relative links connect the portfolio cards to their project pages. This gives me a practical foundation for adding JavaScript interactions and a contact form in future work.

04

What comes next

Add genuine coursework and project artefacts, personalise the writing, and continue making documented improvements through GitHub. Keep refining the site as my skills and interests develop.
