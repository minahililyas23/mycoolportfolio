01

The idea

Create a clear introduction to Minahil Ilyas and her Information Technology studies. The website brings an about page, technical interests, a growing portfolio and a contact form into one consistent experience.

02

What’s implemented

The site uses original HTML and CSS, with vanilla JavaScript for the mobile navigation and contact form feedback. A native server endpoint validates and stores contact submissions. Portfolio cards link directly to their detail pages; the page content remains available when JavaScript is disabled.

03

Connecting the studies

Semantic elements organise each page. CSS selectors define the presentation; DOM queries and event listeners connect buttons and forms to JavaScript functions. The contact form demonstrates the client–server distinction: the browser provides immediate feedback, while the server checks and saves the message.

04

What comes next

Add genuine coursework and project artefacts, personalise the writing, and continue making documented improvements through GitHub. Keep refining the site as my skills and interests develop.
